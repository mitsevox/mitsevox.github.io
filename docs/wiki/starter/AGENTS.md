# Agent instructions

DRAFT STARTER: owner reviews and adopts these rules before use.

Read README.md and CONTRIBUTING.md before working. Verify target and owner identity.
Use a dedicated branch and checkout/worktree; preserve unrelated changes and claim bounded scope.
Inspect available evidence before reconstructing. Keep original binaries, complete debug exports
and trial output out of public Git. Do not change approved build dependencies or access controls.
Keep facts, hypotheses, exact/fuzzy comparisons and complete-build results distinct.
Retain useful partial source in normal source files and register its measured comparisons.
Do not force matches through unsupported flags, patched output or hidden mismatches.
Read and follow the adopted review/merge policy; the starter default is independent blind
accuracy and hostile review with owner-only merges. Do not impose a different policy silently.
For that default, complete the applicable independent passes; authors cannot self-review.
Use focused delta rechecks and final-revision validation; carry forward adequate prior coverage.
Follow the documented merge authority (default: only OWNER_LOGIN merges main).
Do not enable auto-merge, push main or alter repository approval controls without authorization.
Push branches/open PRs only when authorized. Never fabricate results, attribution or approval.
Start CI setup with fresh validation. Implement CI.md's operations using actual project tools;
do not leave successful placeholder commands. Caches/proof reuse are optional later stages.
Keep attribution tracking, contributor display and contribution acceptance independent.
